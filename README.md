# toolsHXP · jherreraxp.github.io

Sitio personal del Dr. José Alfredo Herrera Quispe: herramientas con IA para la docencia.

Cada proyecto vive en su carpeta y ofrece tres opciones:

1. **Usar la app** — enlace a la instancia en funcionamiento.
2. **Prompt para su IA** — versiones para Claude, ChatGPT, Gemini, Copilot, DeepSeek y Kimi (`prompts/*.txt`).
3. **Instalar usted mismo** — código en `.zip` y guía de instalación.

Estructura de un proyecto: `<id>/index.html` (plantilla común), `<id>/proyecto.json` (datos), `<id>/prompts/`, `<id>/codigo/` y `<id>/<id>.zip`. El portal se arma desde `proyectos.json`.
